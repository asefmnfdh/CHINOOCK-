# CHINOOCK — Android Prototype

نمونه اولیه بازی رانندگی سه‌بعدی آفلاین برای اندروید با دوربین سوم‌شخص پشت خودرو.

امکانات فعلی:
- محیط آزمایشی شهری و جاده
- خودروی اسپرت ساده و دوربین تعقیب‌کننده
- دکمه‌های لمسی فرمان، گاز و ترمز
- نمایش سرعت
- کنترل صفحه‌کلید برای آزمایش روی رایانه

این نسخه فقط نمونه اولیه است؛ مدل‌های واقعی خودروهای لوکس، مأموریت‌ها، صداگذاری، منوها و چندنفره آنلاین هنوز تکمیل نشده‌اند.

## ساخت APK
از بخش Actions، گردش‌کار **Build CHINOOCK Android APK** را اجرا کنید. در صورت موفقیت، فایل APK در Artifact با نام CHINOOCK-Android-APK قرار می‌گیرد.
